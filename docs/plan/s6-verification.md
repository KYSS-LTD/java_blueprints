# S6. Проверка поведения и сценарии

**Часы:** H14–32 · **Треки:** B (основной), C · **Веха:** M1 (часть A), M2 (часть B) · **Требования:** FR-11, FR-12, FR-15, FR-19, FR-20

## Цель

Реализовать ключевой контракт кейса: после любых преобразований автоматические тесты подтверждают сохранение поведения. Этап делится на две части: **A** — эталон, сравнение и gate на ручных сценариях (нужен к M1); **B** — трассировка, покрытие, генератор сценариев и бенчмарк (к M2).

## Зависимости

S3 (сборка, запуск, SSE), S2 (граф и узлы для инструментирования), S4 (панели UI).

## Часть B — трассировка, генератор, бенчмарк (H20–32)

| ID | Задача | Трек | Ч | Результат и тесты |

| S6.8 | **Вывод схемы ввода** (`verify/generator/input_schema.py`): последовательность чтений (`Scanner.next*`, `BufferedReader.readLine`, `args`), циклы чтения с границей из прочитанной переменной, константы из условий/`switch`/`enum`, форматы парсинга | A + B | 3 | Тесты: схемы для `demo-orders` и фикстур `scope/02-*` |

| S6.10 | **Бенчмарк и эмпирическая сложность** (`verify/benchmark.py`): масштабируемые сценарии (`scaled`, размеры 1000…8000, шаблон `${N}`), прогрев + 3 замера, медиана, показатель роста `k` (log-log регрессия), счётчики; `POST /findings/{id}/verify` | B | 2,5 | Тест: `k≈2` для O(n²) и `k≈1` для O(n) на фикстурах |
| S6.11 | UI: диалог «Сгенерировать сценарии» (прогресс, покрытие, список), покрытие на графе, график бенчмарка (shadcn Chart «до/после», показатель `k`) | C | 2 | Работает на реальном API |
| S6.12 | Тесты: покрытие и детерминизм генератора на корпусе, негативный контроль gate (E2E), I5 (определённость), нагрузка (gate на 15 сценариях ≤ 20 с) | B | 1,5 | Зелёные тесты, тайминг |

## Критерии выхода

- [x] Эталон записывается на оригинале; повторный прогон на неизменной версии — `PASS` по всем стабильным сценариям.
- [x] Любое изменение вывода/кода выхода/исключения ловится красным тестом с diff; изменение без влияния на вывод — зелёный.
- [x] Нестабильные сценарии выявляются и маскируются либо исключаются с предупреждением.
- [ ] Gate запускается автоматически для преобразований и по кнопке; статус версии виден в шапке.
- [ ] Генератор: покрытие ≥ 80% узлов `demo-orders` за ≤ 60 с, детерминирован.
- [x] «Дебаг» показывает счётчики на узлах; непокрытые узлы выделены.
- [ ] Бенчмарк возвращает показатель роста, совпадающий с ожидаемой сложностью фикстур.
- [x] Отчёты экспортируются в JSON, Markdown и JUnit XML.
