# S8. Оптимизация

**Часы:** H30–40 · **Треки:** A (преобразования), B (gate, бенчмарк), C (UI) · **Веха:** M4 · **Требования:** FR-16, FR-15

## Цель

Превратить находки в безопасные автоисправления: предпросмотр, применение, quality gate (сборка + сценарии), пакетная оптимизация одной кнопкой и измеренный эффект («до 5.2×»).

## Зависимости

S7 (находки, чистота и инвариантность), S6 (gate, кандидаты, бенчмарк), S5 (правки текста), S4–S5 (UI).

Кандидаты: `POST /fixes/{id}/apply` создаёт версию со статусом `candidate` и запускает gate; зелёный — кандидат становится HEAD (`candidate: promoted` в итоге запуска), красный для `behavior_preserving = true` — отклоняется, для `false` остаётся кандидатом до `accept`/`reject`. Если HEAD изменился после создания кандидата, автоповышения нет (`stale`). `accept` не перезаписывает эталоны: после подтверждения расхождений их записывают заново (`kind=baseline`).
