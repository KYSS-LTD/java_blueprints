# S7. Диагностика, Big O и метрики

**Часы:** H22–34 · **Треки:** A (engine), C (UI) · **Веха:** M3 · **Требования:** FR-13, FR-14, FR-15, FR-20 (часть), FR-21

## Цель

Дать пользователю проверяемую диагностику: строку кода и узел графа, объяснение, оценку сложности, вариант исправления с ожидаемым эффектом. Реализовать модель стоимости Big O для метода и произвольного фрагмента и метрики.

## Зависимости

S2 (семантика, чистота, граф), S6.6/S6.10 (трассировка и бенчмарк для «Проверить»), S4.10 (каркас правой панели).

## Критерии выхода

- [x] Оценка сложности вычисляется для метода, цикла и произвольного выбранного фрагмента; цепочка вкладов объясняет результат.
- [x] На `demo-orders` находки ядра найдены, каждая содержит: место (строка + узел), объяснение, оценку сложности, рекомендацию и ожидаемый эффект.
- [ ] Для PERF-находки «Проверить» показывает счётчики и показатель роста; для BUG — сценарий-воспроизведение или честное «не подтверждено».
- [ ] Панель «Анализ» воспроизводит макет: «Проблемы», «Рекомендации», «Метрики», «Сложность», «Оценка производительности».
- [x] Анализ детерминирован и укладывается в 1 с на 1000 строк.
